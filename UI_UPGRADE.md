# LinkForge UI — Ainul Haq

Modernized frontend with developer attribution, responsive dark dashboard, and accessible form controls.

## Apply to your existing VS Code project

Copy the `frontend/src` directory from this ZIP into your existing project (replace matching files), then run `docker compose up --build -d`. Alternatively, use this complete ZIP and copy your existing `.env` into the extracted root.

Open http://localhost:3000. Existing API routes and database services are unchanged.
